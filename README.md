# КРОШ VPN

Статический сайт с интерактивной 3D-моделью на Three.js.

## Запуск

Откройте папку сайта через любой локальный HTTP-сервер. Например:

python -m http.server 4173

Затем откройте http://localhost:4173.

## GitHub Pages

Загрузите содержимое этой папки в корень репозитория. В Settings → Pages выберите Deploy from a branch, ветку main и папку / (root).

## Файлы

- index.html — разделы и тексты
- style.css — оформление и адаптивная версия
- app.js — выбор локаций, тарифов и инструкции
- scene.js — модель Кроша и анимация
- three.module.js — Three.js 0.170.0

Тарифы и локации демонстрационные. Оплата, реальные VPN-серверы и выдача конфигураций не подключены.
